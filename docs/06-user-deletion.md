# 管理员删除用户

管理员可在 Admin → Users & Roles 查看删除预览并永久删除其他账号。删除者不能删除自己，数据库事务会拒绝删除最后一个有效管理员。删除完成后，目标用户的所有实时连接立即断开；其旧会话无法再解析为用户。

删除身份记录会释放邮箱和 SSO subject。该身份再次登录时创建新的 Pending 账号，通知管理员审批；不会恢复旧账号的集合、权限和配置。

## 数据处理

- 删除用户本人拥有的 collections 及集合成员、文献关联；组织 Library 文献和文献内容保留。该用户在其他集合的成员关系级联移除，他添加的文献关联保留。
- 删除个人 providers、API keys 和 lenses。清除其私有 Lens annotations 与没有共享输出的 runs。共享给组织的 Lens 输出保留，保存 Lens 名称、颜色和原 owner 昵称快照；owner 昵称显示为 “Deleted user”。
- 保留用户的评论及回复正文和讨论结构，将作者外键置空，界面显示 “Deleted user”。用户自己的 inbox 消息删除；发给其他人的历史通知保留，发送者显示 “Deleted user”。
- 删除该用户所有当前投票并重新按剩余投票汇总；他人收到的历史投票通知保留并匿名化。
- 删除待审批消息以及作为消息接收者的通知记录。

预览展示待删除集合、评论、个人 Lens/provider、私有 Lens 输出和共享 Lens 输出数量。执行删除时后端重新检查权限以及最后管理员保护条件，再在事务内处理数据并删除用户行。

## 部署

全新数据库使用更新后的 `schema.sql`。已有数据库先运行 `pnpm db:user-deletion`，命令会调整匿名作者字段、通知外键并为 Lens 输出补齐展示快照。此升级保留现有业务记录，可重复运行。
